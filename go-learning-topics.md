# Go Learning Topics

Areas to explore with this project:

1. **Testing patterns** - Table-driven tests, mocks, benchmarks, golden files
2. **Concurrency** - Goroutines, channels, worker pools for parallel processing *(focus)*
3. **CLI design** - Flags, subcommands, config files, interactive prompts
4. **Data processing** - Streaming, pipelines, functional patterns *(focus)*
5. **I/O & formats** - Multiple file formats, export options, serialization
